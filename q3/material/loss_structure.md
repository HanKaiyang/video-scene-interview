# 输出 JSON 的字段长度（单条样本，按 token 计）

模型用一个 decoder 直接生成整个 JSON 字符串，prompt 与输入部分全部 mask，loss 只算在这些目标 token 上。

| 字段 | 平均 token | 占比 |
|---|---:|---:|
| `"scene":["办公室"]` | 6 | 14.0% |
| `"is_quiet":1` | 4 | 9.3% |
| `"caption":"…"` | 21 | 48.8% |
| `"answer":"…"` | 12 | 27.9% |
| 合计 | 43 | 100% |

两个文本字段合计 33 / 43 = **76.7%**；两个分类字段合计 10 / 43 = 23.3%。
